La rotación en una frase

Cada vez que el jugador gira, el juego aplica una matriz de rotación R(θ) a los puntos de la figura y después los traslada a la posición del jugador. El ángulo θ nunca es fijo: viene del mouse, del joystick o de un guardia que gira. Mueve θ y mira cómo cambian las tres cónicas de abajo.

Rotación R(θ)x′ = x·cos θ − y·sin θ y′ = x·sin θ + y·cos θ
Traslación al centro (h, k)x = h + x′ z = k + y′
Inversa (ejes locales)x′ = (x−h)cos θ + (z−k)sin θ y′ = −(x−h)sin θ + (z−k)cos θ

Código base que usan casi todos los juegos (ciclo while):

function rotar(x, y, theta) {
  var c = Math.cos(theta), s = Math.sin(theta);
  return [x * c - y * s,  x * s + y * c];   // x', y'
}

1 · La elipse: zona de visión

Los cuadros verdes están dentro de la zona de visión y los rosados fuera. El triángulo cian es el jugador y la elipse está delante de él.

MinecraftMetal Gear SolidValorantLeague of Legends
Ecuación estándar (sin rotar)x²/a² + y²/b² = 1
Ejes rotadosx′ = (x−h)·cos θ + (z−k)·sin θ y′ = −(x−h)·sin θ + (z−k)·cos θ
Zona de visión (dentro si…)x′²/a² + y′²/b² ≤ 1
Centro (traslación delante del jugador)h = px + d·cos θ k = pz + d·sin θ
Ecuación general con tu θ (centro en el origen)

  p = rotar(a * Math.cos(t), b * Math.sin(t), theta);
  dibujarPunto(h + p[0], k + p[1]);
  t = t + 0.05;
}
q = rotar(bx - h, bz - k, -theta);

2 · La parábola: granadas, flechas y saltos

Parábola con p = 1,5 rotada θ alrededor de su vértice V. Eje naranja, foco F verde y directriz rosada.

FortniteFree FireAngry BirdsMinecraft (flechas)
Ecuación estándary = x²/(4p)
Trayectoria de una granada (ángulo α)y = x·tan α − g·x²/(2v²cos²α)
Parábola rotada θ (vértice en el origen)(x′)² = 4p·y′ con x′ = x·cos θ + y·sin θ y′ = −x·sin θ + y·cos θ
Ecuación general con tu θ

Si la cámara se inclina (roll) o el juego usa ejes girados, la trayectoria vertical de una granada se ve como una parábola rotada.

t = -6;
while (t <= 6) {
  x = t;
  y = t * t / (4 * p);          // eje y'
  q = rotar(x, y, theta);       // rotación
  dibujarPunto(h + q[0], k + q[1]);
  t = t + 0.1;
}

3 · La hipérbola: escape de planetas y haces de luz

Hipérbola con a = 3 y b = 2 rotada θ. Las asíntotas (cian) guían las ramas; los puntos verdes son los focos.

Kerbal Space ProgramElite DangerousLinterna sobre una pared
Ecuación estándarx²/a² − y²/b² = 1
Asíntotas y focosy = ±(b/a)·x c² = a² + b²
Hipérbola rotada θx′²/a² − y′²/b² = 1 con x′ = x·cos θ + y·sin θ y′ = −x·sin θ + y·cos θ
Ecuación general con tu θ
t = -1.6;
while (t <= 1.6) {
  x = a * Math.cosh(t);
  y = b * Math.sinh(t);
  q = rotar(x, y, theta);
  dibujarPunto(h + q[0], k + q[1]);
  t = t + 0.05;
}
